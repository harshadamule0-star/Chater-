# Chatter

Instagram-style social media app prototype built with Flutter.

## Run
1. Install Flutter.
2. Open this folder in Android Studio or VS Code.
3. Run `flutter pub get`.
4. Run `flutter run`.

This prototype contains the UI/navigation for Feed, Stories, Reels, Search,
Notifications, Profile, Messages, and Create Post. Firebase/backend and
real media upload are intentionally left for the next phase.
